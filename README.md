# Breakline — 2D Snooker

A polished browser-based top-down 2D snooker practice game.

## Play

Open `index.html` in a browser or visit the GitHub Pages site. Move the cursor around the cue ball to aim, adjust shot power, and click the table to shoot. Red balls score 1 point; colors score their standard snooker values.

## Built with

Vanilla HTML, CSS, JavaScript, and Canvas 2D. No build step required.
