# Breakline — 2D Snooker

A polished browser-based top-down 2D snooker game with a two-player turn-based frame.

## Play

Open `index.html` in a browser or visit the GitHub Pages site. Move the cursor around the cue ball to aim, adjust shot power, and click the table to shoot. Player 1 and Player 2 alternate after each stroke. Reds score 1 point; colors score their standard snooker values. Use the Sound button to toggle synthesized ball-collision and pocket-drop effects.

## Built with

Vanilla HTML, CSS, JavaScript, Canvas 2D, and the Web Audio API. No build step required.
